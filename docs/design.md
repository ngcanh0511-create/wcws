# World Cup 2026 Dashboard

## Tech Stack

Frontend:
- HTML5
- CSS3
- Vanilla JavaScript

Backend:
- Existing REST API

Do not use:
- React
- NextJS
- Vue
- Angular
- TypeScript

## Design Goal

Create a modern World Cup 2026 dashboard.

The website should feel like a sports game menu inspired by FIFA / EA FC.

Keep the design clean and easy to read.

Avoid:
- Heavy animations
- WebGL
- Complex effects
- Overcrowded layouts

## Visual Style

Theme:
- Modern sports dashboard
- Bright and energetic
- Premium but lightweight

Background:

## Background

Use a blurred World Cup 2026 stadium image.

Apply:
- Dark overlay
- Low opacity
- Background must not affect readability

## Layout

### Header

Logo

Navigation:
- Matches
- Standings
- Teams
- Stadiums

### Hero Section

World Cup 2026

USA • Canada • Mexico

Featured Match Card

Countdown Timer

### Today's Matches

Display matches in responsive cards.

Each card shows:
- Team logo
- Team name
- Match time
- Match status

Status:
- LIVE
- UPCOMING
- FINISHED

### Standings

Responsive table.

Show:
- Position
- Team
- Played
- Points

### Featured Match

Large highlighted card.

Contains:
- Home team
- Away team
- Stadium
- Countdown

### Footer

Simple footer with copyright and API source.

## Responsive Requirements

Desktop:
4 cards per row

Tablet:
2 cards per row

Mobile:
1 card per row

## Animations

Allowed:
- Hover effects
- Smooth transitions
- Fade in

Avoid:
- Parallax
- WebGL
- Long animation sequences

## Code Requirements

Use:
- Semantic HTML
- Modern CSS
- CSS Variables
- Flexbox
- CSS Grid
- Fetch API

Write clean and maintainable code.

Separate files:
- index.html
- styles.css
- app.js
